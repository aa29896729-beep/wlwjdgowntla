# 📊 단어 빈도 및 감성 분석 프로그램 (Streamlit)

Python과 Streamlit, 형태소 분석기(`kiwipiepy`)를 활용하여 텍스트 파일(.txt)의 단어 빈도를 분석하고 시각화(가로 막대그래프, 워드클라우드)하며, 간단한 긍정·부정 감성 분석을 수행하는 웹 애플리케이션입니다.

---

## 🛠 주요 기능

1. **텍스트 파일 업로드**: 분석하고자 하는 `.txt` 파일을 업로드합니다.
2. **사용자 사전 설정**: 쪼개지지 않기를 원하는 단어들을 쉼표(,)로 입력하여 Kiwi 형태소 분석기에 등록합니다.
3. **파일 내용 미리보기**: 업로드된 텍스트의 내용을 확인할 수 있습니다.
4. **전처리 및 단어 빈도 분석**: `kiwipiepy`를 이용해 2글자 이상의 명사만 추출하고, 상위 단어 개수를 슬라이더로 조절하여 빈도표를 확인합니다.
5. **시각화 (탭 구성)**:
   - **가로 막대그래프**: 상위 N개 단어의 빈도를 시각화합니다.
   - **워드클라우드**: 추출된 명사를 기반으로 워드클라우드를 생성합니다.
6. **감성 분석**: 동사·형용사의 기본형태(~다) 변환을 포함하여 긍정·부정 감성 사전을 비교하고, 단어 개수, 목록 및 원그래프(Pie Chart)를 제공합니다.

---

## ⚙️ 사전 준비물

* **한글 폰트 파일 (`NanumGothic.ttf`)**: 그래프 및 워드클라우드의 한글 깨짐 방지를 위해 프로젝트 루트 디렉토리에 반드시 위치시켜야 합니다.
